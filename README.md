# AmtBuddy

Test landing page: German paperwork in plain English, for new arrivals in Germany.

Before running ads, edit the settings block near the bottom of `index.html`:
- `FORM_ENDPOINT`: a free Formspree form link (collects signups)
- `PREORDER_LINK`: a €9 Stripe Payment Link
- `META_PIXEL_ID`: optional, to see which ads bring signups

General information only, not legal advice.
