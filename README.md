# AmtBuddy

Test landing page: German paperwork in plain English, for new arrivals in Germany.

Free survey page (no payment). Answers go to a Google Sheet:
1. Create a Google Sheet, open Extensions → Apps Script, paste `google-apps-script.gs`, save.
2. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Copy the web-app URL.
3. Paste it into `FORM_ENDPOINT` near the bottom of `index.html`.
4. Optional: `META_PIXEL_ID` to see which ads bring signups.

General information only, not legal advice.
